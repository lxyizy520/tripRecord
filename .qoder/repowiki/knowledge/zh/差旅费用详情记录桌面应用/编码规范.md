- 每个实体（行程/住宿/餐饮/交通）均提供成对的 add/update/get/delete/query 函数，统一通过 `get_conn()` 获取连接并在 try/finally 中关闭。
- 数据库初始化采用幂等设计：`CREATE TABLE IF NOT EXISTS` 配合 `ALTER TABLE ADD COLUMN` 容忍重复执行，迁移函数通过计数判断避免重复迁移。
- 截图与发票以相对路径（正斜杠）存入数据库，读取时通过 `rel_to_abs()` 拼接 `BASE_DIR` 解析绝对路径，删除时同步清理物理文件。
- UI 对话框类继承 `tk.Toplevel`，构造函数接收可选 `record` 区分新增/编辑模式，界面构建集中在 `_build()`，保存逻辑集中在 `_save()`。
- Excel 导出统一使用 openpyxl 的 PatternFill/Border/Font/Alignment 设置表头高亮、边框、金额列右对齐与两位小数格式，并追加合计行。
