- 所有数据库操作统一通过 `get_conn()` 获取连接，并使用 `sqlite3.Row` 行工厂返回字典式结果，且在 try/finally 中确保 conn.close()。
- CRUD 函数遵循 add_xxx / update_xxx / get_xxx / delete_xxx / query_xxx 命名约定，每个实体（trips/lodging/meals/transports）均成对提供。
- 删除记录时先读取关联附件路径并调用 `remove_screenshot_file` 物理删除文件，再删除数据库行，保持文件与记录一致。
- 附件以相对路径（正斜杠）形式存入数据库，通过 `rel_to_abs` 与 `save_screenshot` 在 BASE_DIR 下按日期子目录组织，便于跨机器迁移。
- Excel 导出统一使用 openpyxl 的 PatternFill/Border/Font/Alignment 构建表头高亮、细边框、金额列右对齐及冻结首行 A2。
- 历史输入项（出发地/到达地/酒店/餐位/交通工具）通过 GROUP BY + MAX(id) DESC LIMIT 50 查询最近记录，回填到 ttk.Combobox values 供用户快速选择。
