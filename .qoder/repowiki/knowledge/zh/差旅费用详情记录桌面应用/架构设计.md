单文件 Python 桌面应用（`差旅记录.pyw`），按职责划分为四层：
- 路径与常量层：通过 `sys.frozen` 判断是否由 PyInstaller 打包，动态确定 `BASE_DIR`、`DATA_DIR`、`SCREENSHOTS_DIR`、`EXPORT_DIR` 与 `DB_PATH`。
- 数据持久化层：`db_init()` 在首次运行时创建 `trips`、`lodging`、`meals`、`transports` 四张表，并通过 `migrate_legacy_trips()` 将旧版 trips 中的餐饮/交通字段迁移到新表；所有 CRUD 操作封装为 `add_*` / `update_*` / `get_*` / `delete_*` / `query_*` 函数，统一经 `get_conn()` 获取连接并以 `sqlite3.Row` 返回字典行。
- 业务工具层：截图保存（`save_screenshot`，按日期分目录存储相对路径）、发票预览（Pillow + ImageTk）、Excel 导出（openpyxl，带样式、合计行、冻结窗格）。
- UI 交互层：主窗口 + 多个 `tk.Toplevel` 对话框（`EditDialog`、`LodgingDialog`、`MealDialog` 等），使用 ttk 控件与 Combobox 历史记忆。
启动入口为 `启动差旅记录.bat`，调用同目录的 `差旅记录.exe`（PyInstaller 产物）；`.reasonix/` 下存放该仓库自身的主题元数据，与本应用无关。
